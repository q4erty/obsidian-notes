#Docker



```
FROM openjdk:21-jdk-slim

WORKDIR /app/java

COPY Main.class .

CMD ["java", "Main"]
```

Этот Dockerfile выполняет следующие действия:

1. **`FROM openjdk:21-jdk-slim`**
    
    - Базовый образ Docker, содержащий JDK 21 с минимальным набором инструментов (`slim` означает "облегченный" образ без лишних зависимостей).
    - Используется для запуска Java-приложений.
2. **`WORKDIR /app/java`**
    
    - Устанавливает рабочую директорию контейнера как `/app/java`.
    - Все последующие команды `COPY`, `CMD` и т.д. выполняются относительно этой директории.
3. **`COPY Main.class .`**
    
    - Копирует файл `Main.class` из текущей директории хоста в рабочую директорию контейнера (`/app/java`).
    - Это предполагает, что `Main.class` уже скомпилирован локально.
4. **`CMD ["java", "Main"]`**
    
    - Указывает команду, которая будет выполняться при запуске контейнера.
    - В данном случае запускается Java-программа `Main`.

### Как использовать этот Dockerfile:

1. **Создать образ:**
    
    `docker build -t java-app .`
    
    - `-t java-app` задает имя создаваемому образу.
2. **Запустить контейнер:**
    
    `docker run java-app`
    
	- Контейнер запустит программу, содержащуюся в `Main.class`.

### Требования:

- Убедитесь, что у вас есть готовый скомпилированный файл `Main.class`.
