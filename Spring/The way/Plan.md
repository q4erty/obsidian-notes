#plan #springboot

### 1. **Введение в Spring Boot**

- [x] Изучите, что такое [[Difference between Spring and Spring Boot|Spring Boot и его отличие от Spring Framework]].
- [x] Установите рабочую среду: Java, Maven/Gradle, IntelliJ IDEA.
- [x] Создайте первое простое Spring Boot приложение (Hello World).

### 2. **Основы Spring Boot**

- [x] Конфигурация приложения: файл [[Core application.properties and .yml|`application.properties` или `application.yml`]].
- [x] Изучите аннотации:  [[Core Spring Boot|`@SpringBootApplication`, `@RestController`, `@RequestMapping`, `@Autowired`]].
- [x] Постройте простые REST API.

### 3. **Работа с базой данных**

- [x] Подключите базу данных (H2, MySQL или PostgreSQL).
- [ ] Изучите [[Core Spring Data|Spring Data JPA: репозитории, аннотации `@Entity`, `@Table`]].
- [x] Реализуйте CRUD-операции.

### 4. **Валидация данных**

- [ ] Изучите аннотации валидации: `@NotNull`, `@Size`, `@Email`.
- [ ] Настройте обработку ошибок через `@ControllerAdvice`.

### 5. **Безопасность (Spring Security)**

- [ ] Настройте базовую аутентификацию и авторизацию.
- [ ] Изучите работу с JWT для защиты API.
- [ ] Реализуйте регистрацию и вход пользователей.

### 6. **Асинхронность и задачи**

- [ ] Изучите аннотации `@Async`, `@Scheduled`.
- [ ] Настройте выполнение задач по расписанию.

### 7. **Обработка ошибок и логирование**

- [ ] Настройте обработку ошибок через `@ExceptionHandler`.
- [ ] Используйте библиотеку логирования (например, Logback).

### 8. **Работа с внешними API**

- [ ] Изучите WebClient и RestTemplate.
- [ ] Реализуйте вызовы внешних сервисов.

### 9. **Тестирование**

- [ ] Покройте приложение unit-тестами с использованием JUnit и Mockito.
- [ ] Изучите Spring Boot Test для интеграционных тестов.

### 10. **Развертывание приложения**

- [ ] Изучите, как создать `jar`/`war` файл.
- [ ] Разверните приложение на Heroku, AWS, или в Docker-контейнере.

### 11. **Продвинутые темы**

- [ ] Работа с кэшированием (Spring Cache).
- [ ] Использование GraphQL.
- [ ] Мониторинг с помощью Actuator и Prometheus/Grafana.
